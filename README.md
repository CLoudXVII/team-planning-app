# Team Planning App

## Дипломная работа: Веб-приложение для организации командной работы

[На хостинге Vercel](https://team-planning-app.vercel.app/)

## Цель проекта

Разработать веб-приложение для организации и планирования работы в командах.

## Основные задачи

1. Провести анализ предметной области.
2. Провести анализ и сравнение существующих систем.
3. Составить портреты целевой аудитории.
4. Определить требования к приложению основываясь на предметной области, аналогах и требованиях целевой аудитории.
5. Спроектировать базу данных и архитектуру веб-приложения.
6. Разработать клиентскую часть.
7. Разработать серверную часть.
8. Развернуть приложение на хостинге.
9. Продумать шаги дальнейшего развития веб-приложения.

## Технологический стек

| Категория       | Используемое решение                                                            |
|-----------------|---------------------------------------------------------------------------------|
| Фреймворк       | [Next.js 14](https://nextjs.org/)                                               |
| UI-библиотека   | [shadcn/ui](https://ui.shadcn.dev/) + [Tailwind CSS](https://tailwindcss.com/)  |
| API             | [Hono.js](https://hono.dev/)                                                    |
| Бэкенд          | [Appwrite](https://appwrite.io/)                                                |
| Аутентификация  | JWT и OAuth 2.0                                                                 |
| Хостинг         | [Vercel](https://vercel.com/)                                                   |

## Архитектура проекта

- **Frontend**: CSR/SSR-комбинация на Next.js.
- **API**: реализован на Hono.
- **Appwrite**: выполняет роль базы данных, системы сессий и OAuth-провайдера.
